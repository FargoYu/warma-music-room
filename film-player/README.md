# 沃玛の播放器

A frame-accurate recreation of the player in Bilibili video
[BV1q1nH6CEbR](https://www.bilibili.com/video/BV1q1nH6CEbR), rebuilt as a real
music player: 12 tracks, each with its own artwork, all of it measured off the
footage rather than eyeballed.

```
python tools/serve.py            # http://127.0.0.1:8770/index.html
```

## How it is put together

Two layers stacked in the page.

**The art layer is the film.** Per song, one lossless still
(`web/assets/pic/NN_0.png`) plus the film's own motion as a whole-frame clip
(`web/assets/anim/NN.webm`, VP9 4:4:4 full range) played over it. The clip is
the entire frame, not a crop: a crop seams wherever content crosses its edge
and freezes everything outside it. It is fetched only when a song is first
played; when the audio stops the clip is paused and left on screen, so a
paused song freezes on the drawing it had reached. The still underneath is the
clip's own first frame.

**The live layer draws only what the film cannot.** The scrub knob (per-song
sprite, riding the film's own track), the elapsed clock (the film's handwriting
lifted into a glyph atlas, on four measured slots), the play/pause key (the film
never shows a pause state) and the heart (the film never shows a like). The
heart is two-tone in the film - a rim in the song's ink, a body in the song's
heart colour - so the rim is kept and the body carries the state. Everything
else is the film's own drawing: the icons, the bar line, the total-time clock.

Pausing is a frozen picture, not a reset one. Skipping keeps the play/pause
state the listener chose; `previous` restarts a song past 3 s. Likes, saves, the
last song and its position persist in `localStorage`; the page never starts
making sound on its own. Media Session drives the same transport on the lock
screen. An audio error steps on and gives up after one turn. The bar is an ARIA
slider whose arrows scrub; a dead dark-mode extension cannot repaint the
palette (`darkreader-lock`).

## Data

`web/js/data.js` is generated by `tools/build_data3.py` from the measurements
in `_frames/` (git-ignored, extracted from the source video) - never hand-edit
it. Per song it carries the palette, the bar and clock geometry, the knob
sprite, the still's URL and the clip's URL.

Rebuilding the artwork needs the extracted footage (`_frames/v/*.jpg`) and the
measurement JSONs:

```
python tools/build_stills.py     # the stills (and the erasers they use)
python tools/build_anim.py       # the per-song clips, from the same erasers
python tools/build_data3.py      # regenerate web/js/data.js
```

order matters: stills, then anim, then data.

## Checks

Ten browser checks, each printing a per-song table and a final `FAILED:` line:

```
python tools/e2e.py          # interactions, freeze-on-pause, the key's glyphs
python tools/data_check.py   # data.js == what the builder computes == what the page paints
python tools/knob_check.py   # knob position/height and that its mask paints a sprite
python tools/clock_check.py  # clock slots, baseline, scale, film axis, glyph pixels, colour floors
python tools/qa_stills.py    # erasure, play/heart erased, still == clip frame 0, page fidelity
python tools/qa_frames.py    # every frame at 30 fps; the wrap is an ordinary step
python tools/qa_perframe.py  # every frame against the film frame it came from
python tools/qa_erase.py     # knob and clock gone from every frame, patches steady
python tools/qa_live.py      # the page on frame k against the clip's own frame k
python tools/qa_play.py      # a song actually plays: the picture keeps moving
```

They need `_frames/` and the served page; they are the project's own instrument
and run against the original footage.

## Layout

```
web/               the player: index.html, js/, css/, assets/ (pic, anim, audio, ui)
tools/             build and measurement tools; the ten checks are the live ones
CLAUDE.md          the measurement doctrine and the traps
_frames/           footage + measurements (git-ignored)
audio_raw/         the original downloads (git-ignored)
```

The artwork and songs belong to their original creators; this is a fan
recreation of the player shown in the video.
